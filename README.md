# 🐾 Pet House - MERN Stack

An online platform for pet sales, dog adoption, pet products,
services, and donations.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Dog Sale & Adoption
- Pet Product Shopping
- Cart & Wishlist
- COD Checkout
- Order Management
- Product Reviews & Ratings
- Dog Breed Information
- Pet Services
- Service Requests
- Stray Dog Donations
- Admin Dashboard
- Admin CRUD Management

## 🛠️ Technologies

### Frontend
- React.js
- React Router
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
